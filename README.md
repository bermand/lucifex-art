# Lucifex

Portfolio site for Lucifex (Elle Berman): sculpture and garments in leather and latex, Dublin.

Static site, no build step: `index.html` plus the `img/` folder. Served at [lucifex.net](https://lucifex.net) via GitHub Pages.

## Updating

Edit `index.html` or replace images in `img/`, commit, push to `main`. Pages redeploys automatically.

## Images

Current work images are AI-generated stand-ins for pieces not yet photographed. Replace each with a photograph of the piece (2400 px on the long edge recommended) using the same filename.
